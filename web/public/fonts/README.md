Add your TrueType font (.ttf) files here.

Examples:
- SweetSansPro-Regular.ttf
- SweetSansPro-Bold.ttf
- SweetSerifPro-Regular.ttf
- SweetSerifPro-Bold.ttf

After adding fonts, ensure the filenames match the references in `src/styles/globals.css`.

To use multiple font families, add separate @font-face declarations with unique `font-family` names.
For example, use `SweetSansFont` for your sans font and `SweetSerifFont` for a serif font.
